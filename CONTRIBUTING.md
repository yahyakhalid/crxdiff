# Contributing to crxdiff

Thanks for helping. Arabic and English are both welcome in issues and pull requests.

## The most useful contribution: a false alarm or a missed change

crxdiff's scores are only as good as the updates it has seen. If an ordinary update
was flagged, or a suspicious one looked clean, open a **False alarm or missed
change** issue with:

1. the extension's Chrome Web Store ID and the two versions;
2. the report's level and reasons (a screenshot is fine);
3. why you think the score is wrong.

You can reproduce a report outside the browser with two packages:

```bash
node scripts/compare.mjs old.crx new.crx
```

## Development

```bash
git clone https://github.com/yahyakhalid/crxdiff
cd crxdiff
npm ci
npm test          # Node's built-in test runner
npm run lint
npm run build     # dist/crxdiff-<version>.zip
```

Load `src/` as an unpacked extension in `chrome://extensions` while you work.

- `src/lib/` is the engine. `crx.js`, `zip.js`, `scan.js`, `snapshot.js`, `diff.js`
  and `risk.js` use no browser APIs and are tested in Node; `monitor.js` takes its
  browser APIs as parameters so it can be tested with fakes.
- `src/background.js` wires the engine to `chrome.*`; the pages are in `src/popup`,
  `src/report` and `src/options`, with shared helpers in `src/shared`.
- `src/vendor/fflate.js` is generated by `npm run vendor:fflate`; don't edit it.
- The real-browser scripts (`scripts/experiment/browser-run.mjs`,
  `scripts/screenshots.mjs`) need Chrome for Testing or Chromium, because branded
  Chrome 137 and later ignore `--load-extension`:

  ```bash
  npx @puppeteer/browsers install chrome@stable
  CHROME=/path/to/chrome node scripts/experiment/browser-run.mjs
  ```

- The routine-update check downloads real releases from GitHub:

  ```bash
  node scripts/fetch-real-releases.mjs /tmp/real
  node scripts/noise.mjs /tmp/real
  ```

## Pull requests

- Keep each pull request to one change, with a test that fails without it.
- A new finding needs a message in **both** `src/_locales/en` and `src/_locales/ar`
  (the tests check that every key exists in both), an explanation (`*_why`), and
  points in `src/lib/risk.js`.
- Any change to scoring: run `scripts/noise.mjs` and say in the pull request how the
  routine-update results moved.
- Untrusted content reaches the DOM only through `textContent` (the `h()` helper).
  Don't add `innerHTML`, and discuss any new permission in an issue first.
- Update `CHANGELOG.md` under an "Unreleased" heading.

## Conduct

Be kind and assume good faith. Harassment or discrimination of any kind is not
accepted; maintainers may remove comments or block accounts that break this.
